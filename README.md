# AI Cookbook

A calm, bilingual guide to working with ChatGPT.

## What you will find

- a step-by-step ChatGPT guide in Polish and English;
- practical examples and ready-to-use materials;
- short lessons and clear explanations.

Everything is kept in one place and designed to be easy to browse and reuse.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
