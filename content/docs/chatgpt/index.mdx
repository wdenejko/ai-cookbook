title: ChatGPT, step by step
description: A calm, practical guide to working with ChatGPT without a fixed agenda or time pressure.
---

This guide is designed to be read in small pieces. There is no schedule and no
need to finish everything at once. Open one chapter, try one idea on a harmless
task, and return when you are ready for the next step.

## A simple path

1. [Start safely](./start-safely) — understand what ChatGPT does, where it can
   be wrong, and which data should stay out of a chat.
2. [Give useful instructions](./better-prompts) — turn a vague request into a
   clear brief without learning a complicated formula.
3. [Work through dialogue](./dialogue) — let ChatGPT ask questions, prepare a
   draft, and improve it in small steps.
4. [Think critically](./critical-thinking) — separate facts from interpretation
   and check important claims.
5. [Create images](./image-generation) — describe purpose and composition,
   then improve one element at a time.
6. [Organize recurring work](./organize-work) — decide what belongs in a chat,
   Project, Memory, or Skill.

## How to use the guide

- If this is your first time, begin with **Start safely**.
- If you already have a task, go directly to **Give useful instructions**.
- If an answer feels convincing but uncertain, open **Think critically**.
- If you want a quick reminder, use the [practice checklist](./practice).
- If you need text you can paste immediately, open the
  [prompt cards](./prompt-cards).

## One idea to keep in mind

Treat every answer as a draft, not as an authority. ChatGPT can help you think,
write, compare, and revise, but you remain responsible for the source material,
important facts, and the final decision.
