---
title: Organize your work
description: Choose a chat, Project, Memory, or Skill according to how long the context should remain useful.
---

Do not save everything in the same place. Choose the smallest container that
matches the life of the task.

| Need | Good place |
|---|---|
| A separate, one-off task | New chat |
| The next step of the same result | Current conversation |
| A longer topic with related chats and files | Project |
| A stable personal preference | Memory or custom instructions |
| A repeated procedure with clear steps | Skill |

## A simple decision

Ask: **Will I need this context again, and in what form?**

- If the answer is no, keep it in the current chat.
- If the same topic will continue with more files, use a Project.
- If it is a stable preference such as tone or formatting, save it as a
  preference.
- If it is a repeatable process with inputs, steps, and quality checks, turn it
  into a Skill.

Feature availability can depend on the ChatGPT plan and workspace settings.
The principle still holds: keep temporary context temporary, and save only what
will genuinely be reused.

## Close the loop

At the end of a useful conversation, ask ChatGPT to prepare:

```text
Summarize the confirmed facts, decisions, important constraints, and next step.
Omit abandoned ideas and the conversation history.
```

This gives you a clean starting point for a new chat or Project without copying
all the noise.
