## Generate a first version

1. Open ChatGPT and choose image creation if your interface asks for a tool.
2. Describe where the image will be used:

```text
Create a calm editorial illustration for a presentation title slide about
responsible AI at work. Horizontal 16:9 composition, one person reviewing a
document with an AI assistant represented as a subtle light pattern. Paper
texture, restrained blue and magenta accents, generous empty space on the left
for a title. No text, logos, or photorealistic faces.
```

3. Check composition, unwanted text, hands, faces, logos, and visual stereotypes.
4. State what to keep and request one change:

```text
Keep the composition and color palette. Remove the extra screen and make the
empty space on the left wider. Change nothing else.
```

## Edit an existing image

Upload an image you own or may edit. Select the area when the interface supports
it, then describe the replacement and what must remain unchanged. Repeat in
small steps instead of requesting a complete redesign.

## Export

Download the final version and rename it clearly. Check the pixel dimensions,
file type, text legibility, and cropping in its real destination. Keep the
prompt and original file so the result can be recreated.

## Finished when

- [ ] The image serves a stated purpose and size.
- [ ] Rights, privacy, and misleading details were reviewed.
- [ ] The downloaded file was tested in its destination.
