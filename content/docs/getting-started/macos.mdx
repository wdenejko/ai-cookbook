## ChatGPT

1. Visit the [official ChatGPT download page](https://openai.com/chatgpt/desktop/).
2. Download the macOS version, open the file, and move ChatGPT to **Applications** if asked.
3. Launch it, sign in, and choose **Keep in Dock** from the Dock icon menu.

## Claude

1. Visit [claude.ai/download](https://claude.ai/download).
2. Choose **macOS**, open the download, and place Claude in **Applications**.
3. Start Claude and sign in. If macOS displays a security prompt, confirm that
   the app came from Anthropic before continuing.

## Gemini

1. Start at [gemini.google.com](https://gemini.google.com).
2. If Google's official Gemini app for Mac is offered for your account and
   region, follow that official download. Otherwise, keep using the web app.
3. In Safari or Chrome you can add the page to the Dock or install it as a web
   app, depending on the browser version.

## Try a safe first task

```text
Turn this rough note into a friendly two-sentence message:
Meeting moved to Thursday at 10. Please confirm.
```

Do not grant access to contacts, files, microphone, or screen until you need
that feature. macOS lets you review those permissions later in **System
Settings → Privacy & Security**.

## Finished when

- [ ] You can identify the official app or web address.
- [ ] The assistant is easy to reopen.
- [ ] Unneeded macOS permissions remain disabled.
