## ChatGPT

1. Open the [official ChatGPT Windows guide](https://learn.chatgpt.com/docs/windows/windows-app).
2. Select the download link and let Windows finish the installation.
3. Open ChatGPT from the Start menu and sign in to your OpenAI account.
4. Right-click its taskbar icon and choose **Pin to taskbar** if you want quick access.

## Claude

1. Go to the [official Claude download page](https://claude.ai/download).
2. Choose **Windows**, open the downloaded installer, and follow its prompts.
3. Start Claude from the Start menu and sign in. Anthropic lists Windows 10 or
   newer as the minimum supported Windows version.

## Gemini

1. Open [gemini.google.com](https://gemini.google.com) in Chrome or Edge.
2. Sign in with your Google account.
3. To make it feel like an app, open the browser menu and choose the option to
   install the site or create an app shortcut. The wording depends on the browser.
4. Pin the new shortcut to the taskbar if useful.

## Check that it works

Paste this harmless test:

```text
Give me three simple ideas for a 20-minute evening meal. Ask about allergies
before recommending ingredients.
```

Confirm that you are on `chatgpt.com`, `claude.ai`, or `gemini.google.com`
before entering account details. Avoid download sites and sponsored copies.

## If something is missing

- A work or school account may block installation or AI services.
- Some features depend on country, age, account type, or subscription.
- If an installer fails, use the official web version instead of downloading it elsewhere.

## Finished when

- [ ] The assistant opens from a trusted source.
- [ ] You can sign in and start a new conversation.
- [ ] You know how to sign out on a shared computer.
