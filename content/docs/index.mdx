## How these guides are written

The guides avoid jargon and do not assume that every feature is available on
every account. Product interfaces and plan limits change, so use the official
links in each tutorial if a button has moved or an option is missing.

<SafetyNote>
Never paste passwords, one-time codes, payment details, medical records, or
confidential work information into an AI chat. Begin with harmless examples and
grant integrations the smallest access they need.
</SafetyNote>
