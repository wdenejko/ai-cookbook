## Create the project

1. In the ChatGPT sidebar, choose **New project**.
2. Give it an outcome-based name such as `Autumn customer event`, not `Miscellaneous`.
3. If asked about project memory, choose the boundary that fits the work. A
   sensitive or separate initiative benefits from project-only context.
4. Add short project instructions:

```text
Purpose: prepare the autumn customer event.
Audience: existing small-business customers in Poland.
Use only files in this project for dates, prices, and confirmed commitments.
Write in plain Polish. Mark assumptions and ask before changing the budget.
```

## Add only useful context

Upload the latest approved brief, schedule, and budget — not every historical
version. Start separate chats for agenda, invitations, suppliers, and risk
review. Give each chat a descriptive name.

## Maintain the project

Once a week, remove obsolete files, mark the authoritative version in its
filename, and summarize decisions in a dedicated project note. Before sharing a
project, check every chat and attachment for information the recipient should not see.

Projects group chats, files, and instructions; availability and collaboration
options can depend on account type. See the
[official Projects guide](https://help.openai.com/en/articles/10169521-projects-in-chatgpt).

## Finished when

- [ ] The project has one clear outcome.
- [ ] Instructions state source and decision boundaries.
- [ ] Current files and conversations are easy to identify.
