## Step by step

1. Open ChatGPT and select **Search** from the tools menu when it does not start automatically.
2. Include a date and the purpose of your question:

```text
Find the current rules for taking a bicycle on trains from Warsaw to Gdańsk
for travel on 15 August 2026. Prefer official railway operator pages. Give the
rule, price if published, reservation requirement, and a link for each claim.
State when each page was checked.
```

3. Open every source used for a price, deadline, legal requirement, or booking decision.
4. Check that the page applies to the correct country, date, product, and customer type.
5. If the sources disagree, ask the assistant to show the disagreement rather
   than choosing silently.
6. Confirm a high-impact decision directly with the responsible organization.

## Better source requests

- “Prefer the official regulator and provider.”
- “Separate information published this month from older background.”
- “Quote no more than one short sentence; explain the rest in your own words.”
- “Tell me which claims have only one source.”

Use regular search for a quick current answer. For a question that needs many
sources and a documented report, continue to
[Deep Research](./deep-research). See the
[current ChatGPT Search guide](https://help.openai.com/en/articles/9237897).

## Finished when

- [ ] Important links were opened, not merely displayed.
- [ ] Dates and scope match the decision.
- [ ] Uncertainty and conflicting sources remain visible.
