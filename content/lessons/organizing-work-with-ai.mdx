---
title: Organize chats, memory and reusable work
description: Choose a new chat, project, memory or skill according to how long the context and workflow should last.
---

Good prompting is also good organization. Put information in the smallest place
that matches how long you need it.

<LessonGuide slug="organizing-work-with-ai" locale="en" />

<Concept title="Choose the right place">

- **New chat:** a separate, one-off task.
- **Same chat:** the next step of the same result.
- **Project:** an ongoing topic with related chats, files and instructions.
- **Memory:** stable preferences or facts about you that should help in future
  conversations.
- **Skill:** a repeatable method for doing a specific task.

</Concept>

<Concept title="Use memory deliberately">

Ask the assistant what it remembers about you and review the answer. Store useful
preferences, not passwords, confidential records or facts that change often.
Deleting a conversation and deleting a saved memory can be separate actions, so
use the product's memory controls when you want something removed.

</Concept>

<Concept title="Know when to start fresh">

Start a new chat when the goal changes or when old decisions are confusing the
current task. Before moving, ask for a hand-off summary containing the goal,
confirmed facts, decisions, constraints and next step. Paste that summary into
the new chat.

</Concept>

<GoDeeper title="From a good prompt to a skill">

If you use the same sequence repeatedly, turn it into a <Term name="skill">Skill</Term>.
The prompt describes one request; the Skill preserves the whole procedure,
including questions, steps, output format and quality checks.

</GoDeeper>
