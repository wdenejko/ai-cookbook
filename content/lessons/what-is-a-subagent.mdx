---
title: What is a subagent?
description: A subagent is a separate helper ChatGPT hands a focused job to, then gets back just the result.
---

Sometimes the best way to stay focused is to delegate. This lesson covers what a subagent is, why ChatGPT hands work to one, and how a subagent is defined in a single small file.

<Concept title="What is a subagent?">

A <Term name="subagent">subagent</Term> is a second copy of ChatGPT that the main assistant can hand a specific task to, such as "review this code" or "search these files." It works on that task by itself and returns a tidy summary, so the main conversation is not cluttered with all the messy in-between steps.

</Concept>

<Concept title="Why hand work to a subagent?">

Big jobs, like reading through twenty files, create a lot of back-and-forth. If ChatGPT did it all in the main chat, that chat would fill up fast. A subagent does the noisy work separately and returns only the conclusion, keeping the main thread clean. Subagents can also be specialists, and can even run in parallel.

</Concept>

<Concept title="How is a subagent defined?">

You define a subagent in a single file. The top lists its name and a short description of when to use it; the rest is its personality and instructions, its "job description." Because it is just a file, you can save it, share it, and reuse it across projects.

</Concept>

<GoDeeper title="Does the subagent see our whole conversation?">

No. A subagent starts with a clean slate: it gets only the task the main agent hands it, plus its own system prompt. It cannot see the earlier chat unless that context is included in the task. This is exactly why keeping subagents separate protects the main context window, and why a good delegation spells out everything the helper needs.

</GoDeeper>
